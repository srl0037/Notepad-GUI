Simple Notepad GUI application created through experimentation with PySide6, Qt for Python. Created in spare time.

This application was created to mimic a basic notepad app and 
includes the ability to copy/cut/paste/redo/undo/clear text, amoung other features, in the menu bar. Additionally, users are able to zoom in/out and quit the application through the menu bar. The tool bar hosts the text formatting features. Users are able to bold, italicize, and underline text. The user can also change the font size, font family, and text color to their prefrences.

Future iterations of this notepad could include the ability to save the text as files, or the creation of a text editor using this notepad as a backbone.
